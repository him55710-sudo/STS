# STS 커머스 무결성 — 불변 규칙

> **"Commerce must be invisible until intent appears."**
> 상거래는 의도가 나타나기 전까지 보이지 않아야 한다.
>
> 이 문서는 제품 철학이 아니라 **강제되는 계약**이다. 아래 규칙은 코드의 타입·테스트·
> 데이터 구조로 방어되며, 위반하려면 테스트가 깨진다. 새 기능이 규칙과 충돌하면
> 규칙이 아니라 기능을 바꾼다.

---

## 불변 규칙 (Immutable Rules)

### 1. exact 상품은 살 수 없다 (Exact cannot be bought)

크리에이터가 "이것을 입었다"고 확정한 상품에는 **광고가 개입할 수 없다.**
돈으로 exact 자리를 살 수 있다면 태그 전체의 신뢰가 무너진다.

강제 방식:
- `SponsoredPlacement`는 similar 슬롯 전용 구조이고, `sheet-model`의 `sponsoredSimilar`는
  착용 상품·오퍼 섹션과 **별개의 필드**다.
- `selectSponsoredSimilar()`는 착용 상품 id를 받아 자기 자신을 후보에서 제거한다.
  자기 자신을 타깃한 지면은 무시된다.
- 시드 상품 **전수 검사** 테스트가 광고 슬롯에 착용 상품이 오지 않음을 확인한다.
- 별개로, `exact` 관계는 DB 제약(`exact_requires_verifier`)상 **사람의 확인** 없이 만들 수 없다.

### 2. sponsored는 항상 라벨된다 (Sponsored always labeled)

광고는 similar 대안에만 닿고, **언제나 "Sponsored" 라벨과 함께** 노출된다.

강제 방식:
- `SponsoredPlacement.label`은 타입상 필수이며, 비어 있으면 `"Sponsored"`로 채워진다 —
  무라벨 노출 경로가 존재하지 않는다.
- UI(ProductSheet)는 라벨 배지를 항상 렌더하고, 광고 카드는 점선 테두리로 오가닉과 구분된다.
- 광고는 exact 판정·오퍼 랭킹·피드 랭킹에 **관여하지 않는다.** 바꿀 수 있는 것은
  similar 대안의 구성과 순서뿐이다.

### 3. 수수료가 피드 랭킹을 지배하지 않는다 (Commission does not dominate feed ranking)

강제 방식:
- 피드 랭커의 수수료 가중치(0.03)는 다른 모든 축(취향 .24 / 크리에이터 .22 / 품질 .20 /
  신선도 .18 / 새로움 .10)보다 작고, **로드 시점 단언**이 이를 강제한다.
- 오퍼 랭커도 동일: 수수료 0.08 < 가격 0.30, 신뢰 0.26. 입력은 10%에서 절단된다.
- 테스트가 "수수료 90% 게시물이 신선하고 반응 좋은 게시물을 이기지 못함"을 확인한다.
- 수수료 축이 전체 가중치의 5%를 넘지 않는다.

### 4. 일상 비커머스 콘텐츠는 불이익을 받지 않는다 (Everyday non-commerce content is not penalized)

강제 방식:
- 품질 점수는 **커머스 밀도를 보지 않는다.** 상품 0개 게시물과 8개 게시물의 품질 점수가
  동일 조건에서 같다 (테스트로 확인).
- 무결성 페널티는 링크가 있을 때의 **구매 불가 비율**에만 적용된다. 링크가 없으면 0이다.
- 다양성 후처리가 상품 밀집 게시물의 연속 노출(4연속)을 끊는다 — 피드가 카탈로그로 보이지 않도록.

### 5. 매출은 백스테이지에 산다 (Revenue primarily lives backstage)

공개 표면(피드·발견·게시물·공개 프로필)에 **다음이 존재하지 않는다**:
가격 · 수수료 · 제휴율 · 구매 CTA · 상품 개수 · 상시 쇼핑 배지.

금액은 크리에이터 본인의 **비공개 스튜디오(`/studio`)**에만 있다: GMV · 전환 · 수익 · 지급.
공개 프로필은 정체성 · 스타일 · 게시물 · 팔로워 · 숍만 보여준다.
"수수료 70%" 같은 문구는 공개 표면 어디에도 광고되지 않는다 (온보딩 포함).

## 상호작용 계약 (변경 금지)

```
Idle          평범한 라이프스타일 콘텐츠만. 상거래 표면 0.
  ↓ 화면 탭 (의도 표명)
Hint          shoppable 오브젝트가 ~850ms 은은하게 드러남
  ↓ 오브젝트 탭
Silhouette    얇은 실루엣 하이라이트 (bounding box 금지)
  ↓
Product Sheet 1. 착용/exact 상품
              2. 주 판매처 CTA
              3. 다른 판매처 (유용할 때만)
              4. 비슷한 스타일  ← 광고가 닿을 수 있는 유일한 곳
              5. 절제된 제휴 고지 한 줄
```

제휴 고지는 경제적 이해관계를 공개하되(표시광고법) **수수료율·수익 배분율은 노출하지 않는다.**
그 숫자는 시청자의 구매 결정에 필요 없고, 크리에이터의 비공개 정보다.

핵심 오브젝트 상호작용 모델(ObjectLayer의 힌트·실루엣·히트테스트)은 이 감사에서 **변경하지 않았다.**

## 무결성 지표 (`lib/metrics/integrity.ts`)

성장 지표(GMV·수수료)보다 **먼저** 보는 숫자들. 나빠지면 제품이 카탈로그로 변질되고 있다는 신호다.
관리자 대시보드에 노출되며 임계를 벗어나면 "주의" 배지가 붙는다.

| 지표 | 정의 | 권장 |
|---|---|---|
| `organic_content_ratio` | 연결 상품 0~1개인 게시물 비율 | **≥ 40%** — 평범한 일상 콘텐츠가 충분히 남아 있는가 |
| `commerce_heavy_ratio` | 연결 상품 3개 이상인 게시물 비율 | **≤ 50%** — 피드가 카탈로그로 변질되고 있지 않은가 |
| `hide_rate` | 노출 대비 숨김/관심없음 | **≤ 5%** — 상거래 노출이 과한지 알려주는 조기 신호 |
| `creator_retention` | 이전 기간 발행자 중 이번 기간 재발행 비율 | **≥ 30%** — 수익만 좇는 설계는 이 지표를 떨어뜨린다 |

## 검증

`npm test` — 90/90 통과. 무결성 전용 스위트(`tests/integrity/`)가 위 규칙을 직접 검사한다:

- exact 오염 불가 (자기 타깃 지면 무시 + 시드 전수 검사 + 오퍼 섹션 분리)
- 무라벨 광고 경로 없음 (공백 라벨 → 기본 라벨, 일시중지 지면 미노출)
- 광고는 타깃된 similar 슬롯에만 노출
- 수수료 가중치가 모든 축보다 작고 전체의 5% 미만
- 상품 0개 콘텐츠 무감점 · 지표 4종 경계값

브랜드는 전 코드에서 **STS**로 통일했다 (레거시 OBJET/SEEIT 잔재 제거).

## 남은 항목

- 광고 지면은 아직 시드 데이터다 (`SEED_PLACEMENTS`). 실제 광고 판매 시
  `sponsored_placements` 테이블로 옮기되, `selectSponsoredSimilar()`의 불변식은 그대로 유지한다.
- 신고/차단, 노출 빈도 상한(frequency cap), 광고 성과 리포팅은 범위 밖이다.
- `hide_rate`의 노출 분모는 현재 로컬 이벤트 집계를 쓴다. 서버 임프레션 로깅이
  완비되면 그 값으로 대체한다.
