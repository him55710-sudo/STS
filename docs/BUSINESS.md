# STS 사업 모델 — Pinterest와의 차별화 및 수익 구조

> **STS = See it. Tap it. Shop it.**

## 1. 코어 루프 (확정된 BM)

```
크리에이터가 게시물 업로드
   ↓
STS AI가 게시물 속 "모든 상품"을 자동 인식·링크 연결   ← 크리에이터 추가 작업 없음
   ↓
시청자는 사진 속 물건을 탭 → 상품 페이지로 바로 이동 → 구매
   ↓
제휴 브랜드 상품이면: 판매 수수료를 [크리에이터 70% : STS 30%]로 배분
   ↓
크리에이터는 제휴 브랜드 아이템을 더 자주 입고 올림 → 제휴 브랜드 자연 바이럴
   ↓
바이럴 실적 데이터로 신규 브랜드 제휴 영업 → 카탈로그·수수료 풀 확대
```

핵심 플라이휠: **제휴 브랜드일수록 크리에이터가 돈을 벌고, 크리에이터가 돈을 벌수록 제휴 브랜드가 노출된다.**

## 2. Pinterest와의 차별화

| | Pinterest | STS |
|---|---|---|
| 상품 태깅 주체 | 판매자/브랜드가 카탈로그 연동·핀에 태그 | **AI가 게시물 전 상품 자동 태깅**, 크리에이터는 확인만 |
| 인터랙션 | 핀 저장 → 상품 상세로 이동 | **사진 속 물건 자체를 탭** (버튼·태그 아이콘 탐색 불필요) |
| 크리에이터 수익 | 직접적 수익 배분 구조 없음 (외부 제휴링크 의존) | **플랫폼 내장 수수료 셰어 70%** — 링크 작업 0초 |
| 구매 도달 | 핀 → 상세 → 외부 사이트 (경로 김) | 탭 → 시트 → **상품 페이지 딥링크** (2탭) |
| 공급 동기 | 노출·트래픽 | **게시물 = 수익 자산** (발행 즉시 "판매 1건당 ₩X" 표시) |
| 데이터 자산 | 보드/저장 기반 취향 그래프 | **객체 단위 구매 의도 그래프** (어떤 장면의 어떤 물건이 팔리는가) |

Pinterest는 "영감을 저장하는 곳", STS는 **"착장이 곧 매대인 곳"**. 태깅 비용이 0이므로 롱테일 크리에이터(팔로워 1천~10만)까지 전부 수익화 가능 — Pinterest/LTK가 커버하지 못하는 공급층.

## 3. 수익 아이템 (단계별)

1. **제휴 수수료 스프레드 (지금)** — 제휴 네트워크/브랜드 수수료의 30%. 코어.
2. **브랜드 부스트** — 제휴 브랜드가 자사 상품의 "유사 상품" 슬롯·후보 상단 노출을 구매 (CPC/CPS). 광고 표기 필수.
3. **Sponsored Object** — 비제휴 게시물의 미연결 객체에 브랜드가 자사 상품을 입찰 연결.
4. **크리에이터 Pro 구독** — 상세 전환 분석, 팔로워 인사이트, 정산 우선 지급, 커스텀 숍 페이지.
5. **브랜드 대시보드 (B2B SaaS)** — "어떤 착장 맥락에서 우리 상품이 탭·구매되는가" 객체 단위 인텔리전스.
6. **트렌드 리포트/API** — 객체 단위 구매 의도 데이터셋 라이선스 (커머스·브랜드·리서치).

## 4. 크리에이터 온보딩이 마찰 0인 이유

- 링크 설정: **없음** (AI 자동 연결, 크리에이터는 exact/similar 확인만 — 60초 내)
- 수수료 계약: **없음** (가입 = 표준 70% 배분 동의, 게시물별 자동 적용)
- 정산 확인: 발행 직후 "전 상품 1회 판매 시 ₩X" 즉시 표시 → 애널리틱스에서 누적 확인
