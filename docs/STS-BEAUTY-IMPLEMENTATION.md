# STS 통합 뷰티 웹 구현

2026-11-05. 베트남 우선의 뷰티 커머스 탐색 서비스. 기본 언어는 영어이며 한국어·베트남어를 선택할 수 있다.

## 실행과 주요 화면

프로젝트에서 `npm run build` 후 `npm run start -- --hostname 127.0.0.1 --port 3201`로 실행한다. 현재 로컬 주소는 http://localhost:3201 이다.

- `/`: 일반 성인 여성의 새 립스틱 도포 영상과 원본 크리에이터 루틴 진입. 첫 영상은 Artem Podrez / Pexels의 9초 미러 시연이다.
- `/look/glow-lip`: 실제 바르기 0–5.5초, 거울 확인 5.5–9초를 선택해 재생하고 구간 끝에서 정지한다. `/look/glow-lip?step=mirror-check`로 단계 공유가 가능하다. EN/KO/VI 설명 자막을 제공한다.
- `/creators`: 원본 TikTok 4개, 부위별 제품 레이어, 출처와 개인화 비교, 캡션·단계 메모, 최대 20개 링크 일괄 추가. `?video=7518741157669653790` 같은 직접 링크를 지원한다.
- `/discover`: 룩·제품 검색, 부위 필터, 색상 선택과 Lazada Vietnam 검색.
- `/saved`: 룩·제품·색상 저장. 이전 컬렉션은 `/saved/archive`에 유지한다.
- `/profile`: 피부타입·마무리감·향·기후·민감함 설정, 언어와 계정 진입. 기존 계정은 `/profile/account`에 유지한다.
- `/discover?category=fashion`: 기존 패션 게시물을 원래 ID로 연결한다.
- `/feed`, `/demo`는 홈, `/reels`, `/beauty-demo`는 공통 룩 상세로 연결한다.

모든 소비자 화면이 같은 셸과 다섯 개 모바일 메뉴를 쓴다. 영어 기본값 변경 시 기존 저장·색상 선택은 보존하며, 이후 사용자가 명시적으로 고른 언어는 다시 열어도 유지한다. 저장소 차단 시 이번 방문의 메모리 상태로 이용한다.

## 원본 영상과 제품 근거

초기 TikTok 목록은 Jooshica의 자연스러운 루틴·눈썹 튜토리얼, iam.chae의 데일리 루틴, Sarah Chey의 립 틴트 모음이다. 검색으로 확인한 원본 캡션의 제품명 22개를 루틴별로 제공한다. 브랜드를 국적이나 크리에이터의 외모에서 추론하지 않는다.

공식 TikTok iframe을 그대로 사용하고 제품 정보와 단계 선택은 옆에 배치한다. 원본 링크·크리에이터·음원 정보가 유지된다. TikTok 영상이나 음원을 다운로드하거나 다시 호스팅하지 않았다. 재생이 제한되면 원문 링크, 재시도, 제품 목록을 계속 제공한다.

제품명 언급, 브랜드만 언급, 에디터 참고 제품을 구분한다. 캡션으로 실제 도포 장면이나 정확한 색상·순서를 확인한 것으로 표시하지 않는다. iam.chae의 75.93초 원본은 실제 공식 재생에서 45개 시점을 검토했다. 피부 준비·치크·눈·립·완성의 8개 대략적인 구간을 제공하며 단계 선택 시 영상과 제품 부위가 함께 이동한다. 나머지 영상의 시간은 검토 전까지 비워 둔다. 준비·제품 표시 사이의 공백은 유지한다.

`SOURCE_PRODUCT_STACKS`의 제품 부위는 제품군을 묶는 탐색 필터이며 도포 순서가 아니다. 출처 설명의 제품 옵션만 검색어에 사용한다. 상세 출처와 제한은 `public/beauty-media/routine-media-provenance.md`에 있다.

## 나에게 적용하기

개인 설정은 이 브라우저에 저장한다. rom&nd Juicy Lasting Tint는 브랜드의 광택·덧바르기·과일 향 설명을 취향과 비교한다. Torriden DIVE-IN Serum은 공식 보습 설명과 선택한 건성 루틴의 관련성을 설명한다. 향 회피와 매트 선호처럼 충돌하는 조건을 함께 표시한다.

자료가 부족한 제품은 정보 추가 확인으로 안내한다. 피부 진단, 안전 보장, 피부 적합도 백분율이나 자동 비전 분석 결과를 만들지 않는다. 피부 반응·지역별 전성분·실제 고온다습 환경 지속력은 별도 확인이 필요하다. 현재 분석은 캡션의 제품명 대조와 출처가 있는 비교 규칙이다.

## 콘텐츠·거래의 범위

홈 영상의 실제 브랜드와 색상은 확인되지 않았다. 연결 제품은 에디터 참고 제안이다. 나머지 스타일 룩은 참고 이미지와 가이드로 표시한다. 기존 영상 원본과 자료는 보존했다. 라이선스, 파생본, 검토 구간은 두 provenance 문서에 기록했다.

판매처 연결은 Lazada Vietnam의 명시된 검색 결과다. 검증된 판매 제안·가격·재고·배송·제휴 추적이나 수수료 정산은 아직 연결되지 않았다. 본격 운영에는 원본 콘텐츠의 사용 범위 확인, 제품·색상·구간 검토, 현지 판매 제안과 제휴 계약을 추가해야 한다.
