01
프로젝트 주제 · 목표
왜 시작했는가
Starting point
“SNS 영상이나 사진에서 본 제품을
그 자리에서 바로 사고 결제하고 싶다.”개인적인 불편에서 출발한 질문. 콘텐츠를 보는 순간과 구매하는 순간이 왜 이렇게 멀리 떨어져 있어야 할까.
보는 사람
“저거 어디 거지?”에서 끝난다
캡처 → 검색 → 링크 탐색으로 경로가 길어 구매 의사가 식어버림
크리에이터
링크 작업은 많고 수익은 없다
상품마다 태그와 링크를 수동으로 달아야 하고, 작은 계정은 수익화 수단이 없음
브랜드
무엇이 팔렸는지 모른다
어떤 장면의 어떤 물건이 관심을 받았는지 물건 단위 데이터가 없음
Goal
사진 속 물건 자체가
인터페이스가 되는
Visual Commerce 플랫폼
  • 보는 사람은 탭 한 번으로 구매까지
  • 크리에이터는 링크 작업 없이 게시물이 곧 수익 자산
  • 브랜드는 물건 단위로 관심과 판매를 확인
02
방향 설정 과정
무엇을 선택하고, 무엇을 버렸는가
Decision 1
어떤 형태로
만들 것인가
기존 SNS에 붙이는 애드온 기능
선택자체 플랫폼
애드온은 기술 검증은 빠르지만 콘텐츠·구매·정산 데이터를 우리가 갖지 못함. 플랫폼으로 결정.
Decision 2
누구에게
먼저 갈 것인가
선택20대 초 여성
카테고리: 패션
패션은 확실한 수요를 확인하기 어렵고 시장이 너무 넓어 초기 팀이 파고들 지점이 없었다.
Decision 3
카테고리를
뷰티로 전환
한국 뷰티 시장 전체
선택K-뷰티 × 동남아
뷰티는 제품이 명확하고 콘텐츠와 결합이 강하다. 다만 한국 내 시장도 너무 넓어, 동남아의 K-뷰티 수요로 초점을 좁혔다.
Now
공급과 유입을
동시에 만든다
진행 중소규모 화장품 브랜드와 버티컬 제휴 논의
예정소규모 인플루언서 사진 확보 → 유저 유입
제휴 브랜드 상품이 태깅된 콘텐츠가 첫 유입 통로. 작은 브랜드와 작은 계정이 먼저 돈을 버는 구조를 검증한다.
Next
상품 폭을
넓힌다
확장패션
확장가전 · 라이프스타일
객체 자동 태깅은 카테고리에 묶이지 않는다. 뷰티에서 검증한 루프를 그대로 다른 상품군으로 확장.

04
변화 · 발전 과정
Before → After
BEFORE
사각 박스 하이라이트. 상의가 몸 전체처럼 잡히고 가방처럼 겹친 물건은 구분이 안 됨
AFTER
물건 윤곽을 따르는 실루엣. 옷·가방의 실제 경계대로 하이라이트, 겹친 물체도 각각 선택
하이라이트
사각 박스픽셀 경계를 따르는 실루엣, 신발은 좌우 각각
콘텐츠
일러스트 · 가상 브랜드실사 사진 · 실존 상품
AI 실행
서버 API 키 필수브라우저 온디바이스 + 단계별 폴백, 키 없어도 동작
상품 연결
판매처 홈 링크상품 딥링크 + 동일/유사 판별 + 매칭 근거 표시
05

STEP 1
객체 탐지
비전 모델 온톨로지 프롬프트로 의류·신발·가방·시계·주얼리 위치 파악
STEP 2
세그멘테이션

STEP 3
마스크 융합 · 폴리곤
클래스별 사전 지식 결합, 좌/우 인스턴스 분할, 윤곽 추출 → 곡선 폴리곤
STEP 4
상품 검색 · 리랭크
속성 추출 → 쿼리 변형 → 카탈로그·웹 검색 → 색상·텍스트 복합 리랭크 → 동일/유사 판별
STEP 5
탭 인터랙션
실루엣 하이라이트와 폴리곤 히트테스트, 작은 액세서리 우선 선택, 시트 → 구매 딥링크
Fallback 비전 모델 온디바이스 탐지 마스크 실패 시 박스 데모 데이터  ·  어떤 환경에서도 흐름이 끊기지 않게 설계
